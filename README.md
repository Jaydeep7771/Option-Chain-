# Synapse AI

A FinTech app built for a 48-hour hackathon.

## Structure
- `client/` — React + Vite frontend (the part users see)
- `server/` — Node.js + Express backend (the part that talks to the AI and database)

## Quick start
1. Add your API keys to `server/.env` (see the guide your engineer gave you).
2. In one terminal: `cd server` then `npm install` then `npm run dev`
3. In another terminal: `cd client` then `npm install` then `npm run dev`
4. Open the URL Vite prints (usually http://localhost:5173).
